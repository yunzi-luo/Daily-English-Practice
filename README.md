# G'day 每日口语

每天一课澳洲生活场景英语口语练习：打电话、同事闲聊、看病、租房、孩子学校……

每课包括核心词汇、听力难点（连读/吞音）、两分钟演讲范文、情景对话和救命句，所有英文都可以点开朗读。

网站：https://yunzi-luo.github.io/Daily-English-Practice/

## 结构

- `index.html`：网站页面
- `lessons/index.json`：课程目录（新课在最前）
- `lessons/YYYY-MM-DD.json`：每天一课的内容

新课每天早上自动加入。
